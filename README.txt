PY’s Wallet 3.0 — local preview
Export a backup from 2.0 before updating. Upload index.html, manifest.json, sw.js, icon.png and this README to the existing purple-wallet-v2 repository root. Same local storage key and cents-based data format. Do not upload your backup. Test with sample transactions first. No voice recognition. Receipt entry uses pasted Live Text. Goals, albums, payment plans and claims are simple manual lists, not linked accounting modules. Cloud sync, map, app lock, automatic recurring transactions, statement import and multi-currency are not implemented. Icons are emoji. JavaScript syntax checked; iPhone runtime not tested.
